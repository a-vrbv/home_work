# Банковское приложение

## Описание

Приложение для работы с банковскими операциями: просмотр, фильтрация, сортировка.

## Функции приложения

- Просмотр номеров счета и карты
- Фильтрация операции по статусу
- Сортировка операций по дате(по убыванию, по возрастанию)
- ......остальное в работе

## Установка
1. Клонируйте репозиторий:
git clone https://github.com/a-vrbv/home_work/tree/feature/home_work_10.1

2. Создайте виртуальное окружение:
python -m venv venv

3. Активируйте окружение:
venv\Scripts\activate

4. Установите зависимости:
pip install -r requirements.txt


## Запуск
python main.py
